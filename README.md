# AdoLoop · 日语复读学习机

用 **C++17 / Qt6** 从零实现的一版类 **Aboboo** 外语学习播放器（**默认学习语言：日本語**）。
融合 **LPlayer**（双语字幕 / whisper.cpp + faster-whisper 双引擎 ASR / yt-dlp 在线播放 /
实时翻译 / 单词查询 / 字幕侧栏跳转 / 快捷键全自定义）、**DashPlayer**（Whisper 自动字幕 /
逐句跳转 / 悬停查词）、**Echo-Loop**（意群划分 / 跟读比对 / 原句闪卡）与 **幕境**（语境学词 + 弹幕复习）。

> 开发约束：初版按用户要求以**写代码为主、不强制编译**，不使用 GUI 自动化、不截图；
> 全部设计过程见 `docs/`。**M9 完成首次实际构建**、**M10 补齐播放列表/书签/断点续播**、
> **M11 完成日语化（分词地基）+ 悬停取词 + 词典发音 + 听音查字**、
> **M12 完成读音缓存 + 生词本/闪卡日语化 + 段落复述（P0 最后一块）**：
> MSVC 19.44 + Qt 6.8.3 下 configure/build 退出码均为 0（零 error / 零 warning），
> 产出 `build/src/AdoLoop.exe`（904,192 字节，
> sha256 `15e6b24beb68072d20078e889f9c790318937610145f01b3e9441b9d946767ee`）；
> 另有 M12 的 357 条离线断言全过（累计 M11 的 137 条 + 真实词典回放 22 条，详见 `docs/11-进度日志.md`）。
> 运行期仅做了 `QT_QPA_PLATFORM=offscreen` 无窗口启动自检与纯逻辑校验，界面行为尚未人工验证。

## 功能一览

- 🎵 音视频播放：本地文件 + 在线 URL（yt-dlp 解析直链），**变速不变调**（mpv 首选 / Qt 回退）
- 📊 波形图：整轨峰值、句段分色、点击定位、Shift 拖选 A-B
- 🇯🇵 **日语分词**：按学习语言分词（汉字/假名/片假名 run + 送假名合并 + 助词白名单），
  可选接 MeCab 或 `python + janome/fugashi`（缺失自动用内置启发式）；英语路径行为不变
- 📝 字幕：SRT/VTT/LRC/ASS 解析、双语配对、**字幕侧栏逐句跳转**、
  **字幕悬停/点击取词**（M11：真正按像素命中词，日语「私は学生です」悬停「学生」只查「学生」）、
  无字幕时 **ASR 一键生成**（whisper.cpp / faster-whisper）
- 📖 词典：有道 jsonapi，**按语言取节点**（日语 `jc`：表记 + 假名 + 声调 + 词性 + 释义；英语 `ec`：音标 + 释义 + 例句），
  **发音朗读**（独立播放器，不打断 mpv 主播放）
- 💾 **读音缓存**：查过的词把假名/声调/词性落盘到 `readings.json`，**离线复用**——
  悬停提示、生词本、闪卡、弹幕都能直接显示读音（查词失败不写入，不污染缓存）
- 🎤 **听音查字**（Ctrl+Y）：录音 → 日语 ASR → 查词；也可直接输入汉字/假名/**罗马字**（内置罗马字→假名）
- 🔁 复读：逐句 / A-B 区间 / 全文方案，重复次数与间隔可调
- ✍️ 听写：抠词 / 单句 / 自由三级，实时纠错、错词自动复读词区间、听写汇报（JSON）
- 🎤 随意读：手动 / 声控 / 疯狂跟读，录音保存，原音-跟读包络比对评分
- 🧩 造句练习：词序打乱重组（日语按分词切块，重组不插空格）
- 🃏 原句闪卡：当前句挖空生成，SM-2 间隔复习，**答案词带假名读音**
- 📚 生词本：分级 + SM-2，**日语生词显示 `漢字 [かな] ② 名词 — 上下文`**，
  **弹幕式复习**（生词所在句播放时以 `漢字（かな）` 飘过，点击可查词）
- 🔁 **段落复述**（Ctrl+R，P0 第 10 条）：范围＝当前句 / 意群 / 段落（连续 N 句）/ 全文；
  听原音（**字幕隐藏原文**）→ 静默回忆 → 复述（可选录音 + 包络比对）→ 揭晓对照 → 自评 0–5 → 练习历史（`retell.json`）；
  **没有麦克风也能用**（自动降级为「静默回忆 → 揭晓对照 → 自评」）
- 🗂 播放列表持久化：打开过的文件自动入列表并跨会话保留，双击切换、右键移除/清空
- 🔖 书签：按文件归属，可带备注；菜单/快捷键（`Ctrl+B` 新增、`[` `]` 上/下一个）跳转与删除
- ⏱ 断点续播：记住每个文件上次播放位置，再次打开自动继续（「设置 → 学习」可关闭）
- ⌨️ 快捷键完全可自定义（冲突检测 + 恢复默认）

## 学习语言（M11 起默认日语）

「设置 → 学习」的**学习语言**（`lang/study`，默认 `ja`）决定：

| 受影响项 | 日语（默认） | English |
| --- | --- | --- |
| 分词 | 内置日语启发式（可选 MeCab/janome） | 与 M11 前完全一致（`strutil::tokenizeWords`） |
| 词典节点 | 有道 `le=jap` → `jc`（表记/假名/声调） | 有道 `le=en` → `ec`（音标/释义/例句） |
| 发音音频 | `dictvoice?audio=<speech>`（假名） | `dictvoice?audio=<word>&type=2`（美音，`type=1` 英音） |
| 源语言 / ASR 语言 | 默认跟随学习语言（可手动指定） | 同 |

首次运行即为日语；ini 里若已有 `lang/source`、`asr/language` 等旧值**不会被覆盖**。

## 构建

```bat
:: 前置：Qt 6.5+（Widgets/Multimedia/Network/Concurrent）、CMake 3.21+、MSVC 2022（或 MinGW）
:: 在「x64 Native Tools Command Prompt for VS 2022」中，或先执行 vcvars64.bat：
::   call "C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvars64.bat"

cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release ^
      -DCMAKE_PREFIX_PATH=C:/Qt/6.8.3/msvc2022_64
cmake --build build -j 8
:: 产物：build/src/AdoLoop.exe
```

说明：

- Qt 未装在默认路径时必须给 `-DCMAKE_PREFIX_PATH=<Qt 的 msvc2022_64 目录>`。
- PATH 中若有 MinGW/Strawberry 的 `gcc` 且排在 cl.exe 之前，CMake 会误选 GNU 工具链
  （与 Qt 的 MSVC 库 ABI 不兼容）；此时用
  `-DCMAKE_MAKE_PROGRAM=<ninja 绝对路径>` 并把 MinGW 目录移到 vcvars 之后。
- 也可改用 Visual Studio 生成器：`cmake -S . -B build -G "Visual Studio 17 2022" -A x64`，
  随后 `cmake --build build --config Release -j`（多配置生成器的产物在 `build/src/Release/`）。
- 首次构建后若需运行，请把 `C:\Qt\6.8.3\msvc2022_64\bin` 加入 PATH（或用 `windeployqt` 部署）。

## 外部组件（全部可选，缺失自动降级）

| 组件 | 用途 | 缺失时 |
| --- | --- | --- |
| mpv | 播放后端（变速不变调） | Qt 后端回退 |
| ffmpeg | 波形生成、句段音频提取 | 波形区提示 |
| whisper-cli（whisper.cpp） | ASR 引擎 A | 提示改用 faster-whisper |
| python3 + faster-whisper | ASR 引擎 B（`scripts/faster_whisper_bridge.py`） | 提示安装 |
| yt-dlp | 在线播放 / 字幕下载 | 打开 URL 时提示 |
| **MeCab**（M11，可选） | **日语分词增强**：词 / 读音 / 原形 | 不触发该档，继续降级 |
| **python3 + janome 或 fugashi**（M11，可选） | 同上（经 `scripts/japanese_tokenizer_bridge.py`） | 用**内置日语分词**（默认档，无外部依赖） |

可在「设置 → 通用/引擎」指定各工具路径，留空则自动在 PATH 中查找。
**日语分词的两档外部引擎只在设置了路径时才尝试**（默认走内置启发式，不启动子进程），
任何缺失/失败都自动降级，程序不会因此报错或失败。安装示例：`pip install janome`。

## 快速上手

1. `文件 → 打开文件…`（或 Ctrl+O）打开音频/视频；同名 `.srt/.vtt/.lrc` 自动加载。
2. 无字幕时 `文件 → ASR 生成字幕`（Ctrl+E）生成；双语 `xx.zh.srt` 自动配对。
3. 波形上点击定位；`R` 复读本句；`Shift+拖选` 框 A-B 后 `B` 循环。
4. 字幕上**悬停**（约 450ms）或**点击**某个词即可查词典（日语显示假名 + 声调，
   查过的词读音会缓存下来，之后悬停直接显示 `漢字 [かな]`），点「朗读」听发音；
   点「加入生词本」（读音一并入库）；生词会在其所在句播放时以 `漢字（かな）` 弹幕复习。
5. `Ctrl+Y` 打开**听音查字**：说出生词（录音→识别）或直接输入 `gakusei`（自动转 `がくせい`）查词。
6. `D` 抠词听写、`F` 随意读、`Ctrl+G` 造句、`Ctrl+F` 闪卡、`Ctrl+R` **段落复述**
   （选范围 → 听原音 → 默想 → 复述/录音 → 揭晓对照 → 自评；再按 Ctrl+R 停止）。
7. `Ctrl+B` 在当前时间点加书签（备注可留空），`[` / `]` 跳到上/下一个书签；
   双击左侧「播放列表」/「书签」项即可切换文件或跳转。
8. `设置 → 学习` 可切换学习语言（日本語 / English）、悬停触发延时与「仅点击时查词」、
   段落复述的段落句数与录音开关；`设置 → 快捷键` 自定义全部键位。

## 数据目录（可配置）

```
%APPDATA%/AdoLoop/
├── adoloop.ini         # 设置与键位
├── cache/              # 波形缓存、ASR 缓存
├── recordings/         # 跟读录音 shadow-*.wav、听音查字 soundsearch-*.wav、复述 retell-*.wav
├── dictations/         # 听写汇报
├── vocabulary.json     # 生词本（含 reading/accent/pos/lang）
├── sentencebook.json   # 难重点句库
├── flashcards.json     # 原句闪卡（含 reading）
├── playlist.json       # 播放列表（打开过的本地媒体）
├── bookmarks.json      # 书签（按文件归属，全部媒体共用一份）
├── resume.json         # 断点续播位置（每个文件一条）
├── readings.json       # 读音缓存（词 → 假名/声调/词性，查词成功时写入）
└── retell.json         # 段落复述练习历史（范围/句区间/评分/时间/媒体）
```

> 路径说明：Windows 上 `QStandardPaths::AppDataLocation` 为 `%APPDATA%\<组织>\<应用>`，
> 默认数据目录再拼一级 `AdoLoop` 子目录，因此**实际**数据目录是
> `%APPDATA%\AdoLoop\AdoLoop\AdoLoop\`（`adoloop.ini` 在其上一级）；
> 可在「设置 → 通用 / 引擎 → 数据目录」改到任意位置。

## 已知边界（v0.1）

- **内置日语分词是启发式**（无词性/活用分析）：汉字+送假名（≤3 字）合并、助词白名单拆分、
  整段平假名不切分（`すしをたべる` 作一词）。需要形态素级切分时安装 MeCab，或在设置里填
  python 路径 + `pip install janome`（自动走桥脚本）；两档**本机未实测**（未安装）。
- **读音只来自「查过的词」**：内置启发式分词给不出读音，所以 `readings.json` 的覆盖度
  取决于查词次数（未查过的词在生词本/弹幕/悬停提示里不显示假名，退回原样式）；
  装了 MeCab（或 janome）后分词档也会补读音，但**不覆盖**已查到的词典读音。
- 跟读/复述评分为启发式包络比对（非音素级）；接口可替换。**复述的录音与评分未实测**（无麦克风）。
- 段落复述的「意群」优先用 `Sentence::chunks()`；内置分词剥掉标点后它常退化成整句一段，
  此时按文本标点做按时长比例的切分（`、`/`。` 等作为意群边界）。
- 字幕取词已是真正的像素级词命中（M11）；译文行不参与命中。复述**隐藏原文**期间，
  悬停/点击取词也一并禁用（免得用查词弹窗「偷看」答案）。
- 词典发音依赖有道 `dictvoice`（网络 + 第三方接口）；多读音词条（`speech` 含 `・`）会自动
  回落到按表记取音。**实际出声未人工验证**。
- 听音查字依赖麦克风 + Whisper 引擎；两者缺失时输入框查词照常可用。**录音/ASR 链路未实测**。
- LRC 结束时间默认 3s；「音频导出工具」为后续里程碑。
- 在线字幕（yt-dlp 下载）与自动翻译依赖网络与第三方接口可用性。
- 播放列表只登记**本地媒体**（在线直链会过期，不入列表）；书签与断点续播对在线媒体
  仅在当前会话内有效。断点续播位置 < 3s 不恢复、距结尾 5s 内不记录（视为已听完）。
- **界面交互一律未验证**：菜单/快捷键/面板按钮、字幕隐藏与揭晓的实际显示、
  复述录音链路、生词本与闪卡列表排版——按约束未启动带界面的程序。
