# AdoLoop 项目总览

> 工作名：**AdoLoop**（取自项目目录 `adoodo` + 复读 loop）
> 一句话：用 **C++ / Qt6** 从零实现一版类 **Aboboo** 的**日语**学习播放器，融合
> **LPlayer**（双语字幕 / whisper.cpp+faster-whisper 双引擎 ASR / yt-dlp 在线播放 /
> 实时翻译 / 单词查询 / 字幕侧栏跳转 / 快捷键全自定义）、**DashPlayer**（Whisper 自动字幕 /
> 逐句跳转 / 悬停查词）、**Echo-Loop**（意群划分 / 跟读比对 / 段落复述 / 原句闪卡）与
> **幕境**（语境学词 + 弹幕式复习）。
>
> **学习语言默认「日本語」**（M11 起）：它决定**分词规则**、**词典解析节点**
> （有道日语 `jc` / 英语 `ec`）与**发音音频**；源语言与 ASR 语言默认跟随它，
> 可在「设置 → 学习」切换成 English。英语路径（分词 + `ec` 解析）行为与 M11 前一致。

## 1. 目标

复刻 Aboboo 的核心学习闭环，并吸收四个参照项目的能力：

| 能力 | 来源 |
| --- | --- |
| 波形图主导的**复读**（逐句 / A-B 区间 / 全文方案） | Aboboo |
| **智能断句**（静音检测 + 可调参数）+ 手工断句 | Aboboo |
| **听写**三级：抠词 / 单句 / 自由，实时纠错自动批改 | Aboboo |
| **随意读**（声控 / 手动 / 疯狂跟读）+ 录音管理与比对 | Aboboo + Echo-Loop |
| **变速不变调**（0.25x ~ 2.0x 无极变速） | Aboboo |
| **即点即查字典**、听音查字、生词本（分级 / 间隔复习） | Aboboo + 幕境 |
| **双语字幕**（原语 + 翻译两轨）、字幕侧栏逐句跳转 | LPlayer / DashPlayer |
| **whisper.cpp / faster-whisper 双引擎 ASR**，自动生成/对齐字幕 | LPlayer / DashPlayer |
| **yt-dlp 在线播放**（YouTube/B站等 URL 直读） | LPlayer |
| **原句闪卡**、意群划分、段落复述 | Echo-Loop |
| **弹幕式生词复习**（生词在其所在句播放时以弹幕浮现） | 幕境 |
| **快捷键完全可自定义** | LPlayer |

## 2. 交付约束（用户明确要求）

1. **不操作 GUI**：全部开发仅通过文件读写完成，不接管鼠标键盘、不打开界面。
2. **不截图**：不调用任何截图/屏幕捕获能力。
3. **以写代码为先，不强行编译**：本次交付以「可直接阅读、结构完整、可后续构建」的
   源码 + 文档为主；构建与外部依赖（mpv / ffmpeg / whisper 等）的使用方式写入文档，
   运行期缺失时程序自动降级而非崩溃。
4. **过程文档**：每一步设计/进度写入本 `docs/` 目录下的 Markdown。

## 4. 技术栈

- C++17，Qt 6.5+（Widgets / Multimedia / Network / Concurrent）
- CMake ≥ 3.21；构建/打包全部由 **PowerShell 脚本**驱动（M13）：
  `scripts/build.ps1` 用 `vswhere` + VS 自带的 `Launch-VsDevShell.ps1` 在会话内加载 MSVC 环境
  （**不用 `vcvars64.bat`、不启 cmd.exe**），优先用 VS 自带 ninja；
  `scripts/package.ps1` 产出自带 Qt DLL 与 MSVC 运行库的便携发行包。
- 外部组件（**全部可选、运行期探测、缺失即降级、程序不因缺失而失败**）：
  - `mpv.exe`：首选播放后端（JSON IPC，无需编译期链接 libmpv）
  - `ffmpeg.exe`：波形解码、音频提取
  - `whisper-cli.exe`（whisper.cpp 构建产物）：ASR 引擎 A
  - `python3 + faster-whisper`：ASR 引擎 B（经 `scripts/faster_whisper_bridge.py`）
  - `yt-dlp.exe`：在线播放 / 字幕下载
  - **日语分词增强（M11，可选）**：`MeCab`（填可执行文件路径）或
    `python + janome/fugashi`（经 `scripts/japanese_tokenizer_bridge.py`）；
    两者都没有时使用**内置启发式分词**（默认档，无外部依赖）
