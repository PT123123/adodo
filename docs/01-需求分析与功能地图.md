# 01 需求分析与功能地图

> 依据：Aboboo 官方帮助文档（aboboo.com/docs，3.9 版索引 + 检索到的章节摘要）+
> 用户提供的四个参照项目摘要。本文是「做什么」的权威清单，后续设计（02~10）逐条落地。

## 1. Aboboo 功能盘点（官方文档）

### 1.1 播放与课件

- 支持音视频（近百种格式），打开后**自动断句**，断句不理想可重新断句。
- **波形图主导**：波形上按句段划分，点击波形上的句块即「波形复读」。
- **变速不变调**：全程支持音视频、录音、字典例句朗读等变速。
- **播放列表**：管理多个课件；**书签**（进度条书签/断点记忆）。
- **数据目录**可配置（用户数据、录音、听写记录存储位置）。

### 1.2 断句（Sentence Segmentation）

- **智能断句**：依据「背景噪音、句间停顿、最短句长、允许杂音数、静音去除」五个参数
  寻找句间停顿点。不同音频/片段需不同参数，可全选或局部选择音频后执行。
- **手工断句**：在波形面板上增删/移动断点。

### 1.3 复读（练听力）

- 复读方式可切换：**逐句复读 / 区间复读（A-B）/ 全文复读方案**。
- 键盘控 / 鼠标控 / 进度条控 / 书签控 / 无线鼠摇控 多种操控。
- 「全文复读方案」：面向整篇材料的计划式复读。

### 1.4 听写（三级递进）

| 模式 | 对象 | 说明 |
| --- | --- | --- |
| 抠词听写 | 单词 | 必须有参照文本；播一句暂停；写对一个自动归位；**自动复读单词读音区间**；错词反复听写 |
| 单句听写 | 句子 | 可无参照文本；校对需校对文本 |
| 自由听写 | 篇章 | 整篇连续播放输入；实时纠错、自动批改，生成听写汇报 |

- 消除标点符号对正确率的影响（校对时忽略标点可配置）。

### 1.5 口语（随意读）

- 三种跟读方式：**声控跟读**（播原音→提示音→检测到人声自动开始录音）、
  **手动跟读**（点击录音按钮）、**疯狂跟读**（连续快速跟读）。
- 录音列表：删除、导出。
- 幼儿模式、**Pimsleur（皮姆斯勒）学习法**（间隔复述节奏）。
- 改善口语：播放原音与用户录音的比对。

### 1.6 造句练习

- 给句子打乱词序，用户重组为正确句子。

### 1.7 字典

- 英英 / 英汉 / 汉英 / 图片 / 例句 / 常用搭配 多类字典，**即点即查**。
- **听音查字**：根据读音输入查词（音标/朗读检索）。
- 单词发音（美音/英音真人语音库），例句朗读。

### 1.8 工具

- **难重点句库**（收藏难句）、**分级生词本**（按难度分级）、**单词发音训练**、
  音频提取 / 分割 / 合并 / 导出。

### 1.9 字幕（电影）

- 加载字幕、**中英字幕分离**（双语同屏）、**实时字幕取词**（暂停/悬停取词查字典）。

## 2. 四个参照项目的可复用设计

| 项目 | 直接可借鉴 |
| --- | --- |
| LPlayer | ①双语字幕（两轨字幕按时间配对渲染）②ASR 双引擎抽象（whisper.cpp / faster-whisper 可切换）③yt-dlp 拉流在线播放 ④实时翻译（字幕翻译 provider）⑤字幕侧栏（逐句列表，点击跳转）⑥快捷键完全可自定义（键位注册表 + 冲突检测） |
| DashPlayer | ①Whisper 自动生成字幕（无字幕时一键 ASR）②逐句跳转的干净结构 ③悬停查词（字幕上 hover 单词 → 词典弹窗） |
| Echo-Loop | ①意群划分（句子 → 意群 chunk，按停顿/标点）②跟读比对链路（播放 → 录音 → 特征比对 → 评分）③段落复述（隐藏文本回忆）④原句闪卡（句子卡片 + 挖空） |
| 幕境 | ①语境学词（生词绑定所在句）②弹幕式复习（播放时生词以弹幕从右向左飘过，重复出现加深记忆） |

## 3. AdoLoop 功能清单（最终范围）

### P0（核心闭环，本版必做）

> **完成状态（M12 收尾后）**：P0 第 1–13 条**代码全部落地**（✅ = 实现完成、随工程构建通过，
> 并有 M9–M12 的离线自检覆盖纯逻辑部分）。最新一条缺口「段落复述」在 M12 补齐
> （`study/RetellSession` + `ui/RetellWidget` + 字幕隐藏/揭晓），详见 `docs/08` 第 9 节与 `docs/11` M12。
> 需要外部组件（mpv / ffmpeg / whisper / yt-dlp / MeCab）或人机交互的功能，**实机与界面行为尚未验证**
> ——逐条状态见 `docs/11-进度日志.md` 的「验证状态与遗留」。

1. 音视频播放：文件 + URL（yt-dlp），变速不变调（mpv 首选，Qt 回退）。✅
2. 波形图：整轨峰值显示、句段分色、点击定位、A-B 区间框选。✅
3. 字幕：SRT / VTT / LRC / ASS（基础）解析；双语配对；字幕侧栏逐句跳转；
   实时字幕取词（**M11 起为真正的像素级词命中：悬停/点击**）；实时翻译字幕（在线 provider）。
   > 学习语言默认**日语**（M11）：分词、词典节点、发音音频都按它走，可在设置里切成 English。
4. 智能断句：静音检测五参数；手工断点增删。✅
5. 复读：逐句复读（句末自动暂停/重播 N 次/间隔）、区间复读、全文复读方案。✅
6. 听写：抠词 / 单句 / 自由；实时纠错；听写汇报；抠词自动复读单词区间（日语按分词切词）。✅
7. 随意读：手动 + 声控 + 疯狂跟读；录音保存/导出；原音-跟读比对评分。✅
8. 造句：打乱词序重组（日语按分词切 chip，重组不插空格）。✅
9. 词典：在线查词弹窗（即点即查，日语走 `jc` 节点显示假名+声调）；生词本（分级 + SM-2 间隔复习）；
   难句库；弹幕式生词复习；**词典发音朗读（M11）**；**读音缓存 readings.json（M12：假名/声调/词性离线复用）**。✅
10. 原句闪卡 + 意群划分 + 段落复述（Echo-Loop 链路）。
    - 原句闪卡 ✅（M6，M12 补答案词读音）
    - 意群划分 ✅（M6 `Sentence::chunks()`；M12 段落复述的「意群」范围在其退化时按标点比例二次切分）
    - **段落复述 ✅（M12）**：范围＝当前句/意群/段落（连续 N 句）/全文；
      链路＝听原音（隐藏原文）→ 静默回忆 → 复述（可选录音 + 包络比对）→ 揭晓对照 → 自评 → 历史落盘；
      **无麦克风自动降级为「静默回忆 → 揭晓对照 → 自评」**。
11. ASR：whisper.cpp / faster-whisper 双引擎；无字幕时一键生成；词级时间戳。✅
12. 快捷键完全可自定义；设置持久化（QSettings）。✅
13. 播放列表 / 书签 / 数据目录配置。✅

## 4. 非功能需求

- **降级策略**：mpv/ffmpeg/whisper/python/yt-dlp 任一缺失时，对应功能给出明确提示，
  其余功能照常。
- **异步**：ASR、翻译、词典、yt-dlp 解析全部异步执行，不阻塞 UI。
- **模型-视图分离**：字幕/生词本/听写结果用 QAbstractListModel 驱动列表。
- **可测试**：核心逻辑（断句、对齐、听写校对、SM-2）与 UI 解耦，便于单测。
