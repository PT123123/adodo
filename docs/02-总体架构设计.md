学习逻辑层与领域服务层**不反向依赖 UI**，保证可单测。

## 2. 关键设计决策

### D1 播放后端：mpv JSON IPC 为主，Qt Multimedia 回退

- **为什么不用 libmpv 编译链接**：需要外部库头文件/链接，违反「先写代码、少依赖」。
- **mpv IPC 方案**：`QProcess` 启动 `mpv.exe --input-ipc-server=\\.\pipe\adoloop-mpv`
  （Windows 命名管道），`QLocalSocket` 收发换行分隔 JSON。
  - 优点：变速不变调（`--audio-pitch-correction=yes`）、字幕渲染（`--sub-file`）、
    视频窗口由 mpv 自带，我们只发命令收状态。
  - 播放状态（time-pos / duration / paused / eof）由 `observe_property` 轮询事件驱动。
- **Qt 回退**：`QMediaPlayer` 支持基本播放/定位/变速（Qt 后端变速可能变调，文档注明）。

### D2 波形：外部 ffmpeg 解码 + 本地峰值缓存

- `ffmpeg -i in -f s16le -ac 1 -ar 8000 -` 输出单声道 8kHz PCM，
  边读边算每像素柱峰值（金字塔），缓存到 `数据目录/cache/<filehash>.wavpk`。
- 不引入音视频解码库依赖。

### D3 字幕与句子的统一模型：Sentence

- `Sentence { id, startMs, endMs, text, translation, words[] }`。
- `words[]` 为词级时间戳：来自 ASR 结果（权威）或文本按字符占比插值（估计）。
- 抠词听写、实时取词、弹幕复习、闪卡都基于 `words[]`，一处建模多处复用。

### D4 双语字幕配对：时间重叠匹配 + 滚动校正

- 两轨字幕按 `[startMs, endMs]` 求重叠最多的行配对；
- 一行原文可能对应多行译文 → 合并；零重叠行保留未译状态。

### D5 智能断句 = 能量包络静音检测（五参数）

- 解码 PCM → 帧能量 → 阈值（背景噪音）判定有声/无声；
- 停顿 >= 句间停顿 → 候选断点；合并小于最短句长；允许杂音数抑制毛刺；
- 可选静音去除（把断点处静音从波形显示中压缩）。
- 参数全部可调并可保存为「断句方案」。

### D6 ASR 抽象：两个子进程适配器 + 统一 JSON 结果

```
AsrEngine (接口)
 ├── WhisperCppAsr   → whisper-cli --output-json  解析 JSON
 └── FasterWhisperAsr→ python scripts/faster_whisper_bridge.py → 逐行 JSON
结果统一：{ segments:[ {start,end,text,words:[{word,start,end}]} ] }
```

### D7 学习会话状态机（复读/跟读/听写共用）

- 每类会话是**有穷状态机**，由 `AppController` 注入播放引擎与计时器驱动，
  状态变化通过 `stateChanged` 信号通知 UI。
- 例：逐句复读 = `Playing → PausedAtEnd → (RepeatN) → NextSentence`。

### D8 快捷键注册表

- `AppController` 维护 `QMap<QString /*actionId*/, QKeySequence>`；
- 所有动作通过 `registerAction(id, 默认键位, 槽)` 注册，UI 菜单/按钮绑定同一动作；
- `SettingsDialog` 编辑键位，冲突检测 + 恢复默认。

### D9 数据目录与持久化

```
数据目录(可配置，默认 ~/.adoloop/)
 ├── settings.ini        # QSettings
 ├── cache/              # 波形缓存、ASR 缓存
 ├── recordings/         # 跟读/复述录音 wav
 ├── dictations/         # 听写记录 json
 ├── vocabulary.json     # 生词本（M12 起含读音字段）
 ├── sentencebook.json   # 难重点句库
 ├── flashcards.json     # 闪卡（M12 起含读音）
 ├── playlist.json / bookmarks.json / resume.json   # M10
 ├── readings.json       # 读音缓存（M12）
 └── retell.json         # 段落复述历史（M12）
```

### D10 读音缓存：查词结果持久化，离线复用（M12）

- 内置日语分词给不出读音，MeCab 又是可选项——「查过的词」是唯一读音来源，
  故把 `DictEntry{reading, accent, pos}` 落到 `readings.json`（`core/ReadingStore`）。
- 优先级：查词成功（权威，可覆盖）> 分词引擎读音（只补缺）；**查词失败不写入**，避免污染。
- 消费方：字幕悬停提示、生词本条目、闪卡、弹幕——都在**不联网**的前提下拿到假名。
- 落盘策略与 PlaylistModel/BookmarkModel/ResumeStore 一致（`changed` 信号 → 立即写盘），
  上限 5000 条防无限膨胀。

### D11 段落复述：复用既有链路而非新造轮子（M12）

- 会话仍是有穷状态机（D7 约定）：`PlayingModel → Concealed → Retelling → Revealed → SelfRating`。
- 录音复用 `AudioRecorder::startToBuffer()`，评分复用 `AudioAnalysis::compare`（与跟读同一口径），
  原音提取复用 `extractRangeAudio`（由跟读的 `extractSentenceAudio` 抽出）——不引入新评分体系。
- 无麦克风时**降级而非报错**：跳过录音，走「静默回忆 → 揭晓对照 → 自评」。
- 「隐藏文本」落在 `SubtitleOverlay::setConcealed()`：同时清空词级命中表，
  防止用悬停查词偷看答案。

## 3. 核心数据流

```
打开文件/URL
  ├─ MediaEngine.open()
  ├─ Waveform.generate()      ──异步──▶ 峰值缓存 → WaveformWidget
  ├─ SubtitleModel.load()     （自动探测同名字幕）
  ├─ 无字幕 → 询问 ASR ──▶ AsrTaskManager ──▶ SubtitleModel.importAsr()
  ├─ 自动断句（无字幕时）──▶ Sentence 列表 → TranscriptPanel
  └─ 双语字幕加载 → SubtitleOverlay + 翻译异步填充

播放中
  ├─ positionChanged → 波形游标 / 当前句高亮 / 字幕 / 弹幕触发
  ├─ 点句跳转 / A-B 区间 → RepeatSession
  ├─ 取词 → DictionaryProvider ──▶ DictionaryPopup ──成功──▶ ReadingStore（readings.json，离线复用）
  └─ 生词命中 → DanmakuController 发射弹幕（带读音 → 漢字（かな））

复述（M12）
  ├─ 开始 → RetellSession.buildSegments(范围) → commandPlayRange（同时隐藏字幕原文）
  ├─ 段末 → Concealed（静默回忆）→ [可选] 缓冲录音 → AudioAnalysis::compare → Revealed
  └─ 自评 0–5 → 历史 retell.json（范围/句区间/评分/时间/媒体）→ 下一段
```

## 5. 线程模型

- 全部 UI 在 GUI 线程。
- 异步工作统一 `QtConcurrent::run` + 信号回 GUI，或 `QProcess` 子进程。
- 播放事件（mpv IPC / QMediaPlayer）在主线程信号槽处理，保证波形/字幕同步无锁。
