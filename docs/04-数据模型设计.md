# 04 数据模型设计

## 1. 核心：Sentence（统一学习句）

```
Sentence
├─ id          : int           （在 SubtitleModel 内连续编号）
├─ start/end   : Ms（毫秒）
├─ text        : QString       （原文）
├─ translation : QString       （双语译文，可空）
├─ words       : QVector<WordToken>  { word, start, end }
├─ tokens      : QVector<Token>      （M11 分词结果，可空；含读音/原形/位置）
└─ lang        : Lang                （M11 学习语言，由 SubtitleModel 注入）

WordToken = { word: QString, start: Ms, end: Ms }
Token     = { surface, reading, lemma, begin, length }   （core/Tokenizer.h）
```

**一处建模，多处复用**：

| 功能 | 使用点 |
| --- | --- |
| 抠词听写 | words/tokens → 词级区间自动复读 |
| 字幕取词（悬停/点击） | tokens.begin/length → 像素级词命中（M11） |
| 弹幕复习 | tokens → 命中生词时发射弹幕 |
| 原句闪卡 | text + clozeText()（日语不插空格） |
| 意群/段落复述 | chunks()（M12 的段落复述范围：句/意群/段落/全文） |
| 跟读区间 | start/end |
| 造句练习 | Tokenizer::splitChips(text, lang) |

`words` 优先级：ASR 词级时间戳（权威）> 文本字符占比插值（`estimatedWords()`；
末词吸收取整余量，估计区间铺满整句）。

## 1.1 语言感知分词（M11）

```
Lang（core/Types.h）= English | Japanese      # 默认 Japanese（用户实际学习语言）

Settings::studyLanguage()  "ja"(默认) / "en"        ← app 层
      ↓ 注入（core 不反向依赖 app）
AppController::studyLang() → SubtitleModel::setStudyLang() → Sentence.lang
      ↓
Sentence::lexTokens() → tokens（非空则用）或 Tokenizer::tokens(text, lang)

Tokenizer（core/Tokenizer.h）
├─ tokenize(text, lang)            → QStringList（词表，去标点）
├─ tokens(text, lang)              → QVector<Token>（内置启发式；英语同 strutil）
├─ tokensExternal(Batch)(...)      → 三级降级：MeCab → Python 桥 → 内置
└─ splitChips(text, lang)          → 造句 chip
```

- `Lang::English`：切分规则与 M10 的 `strutil::tokenizeWords` **逐字一致**（保留词内 `-`/`'`）。
- `Lang::Japanese`：内置启发式（汉字/假名/片假名/拉丁/数字 run + 送假名合并 + 助词白名单，
  详见 `docs/06` 第 5 节）。外部两档（MeCab / `scripts/japanese_tokenizer_bridge.py`）为
  **可选增强**，未配置时完全不启动子进程。
- 依赖注入约束：`core` 层不 `#include` `app/Settings`；MeCab/python 路径经
  `Tokenizer::Options` 由 app 层传入。

## 1.2 词典条目（DictEntry）

```
DictEntry
├─ word/reading/accent            # 日语：表记 / 假名 / 声调（如 ②）
├─ pos                            # 日语词性（M12：trs[].pos；英语旧形态有则填）
├─ phoneticUs/phoneticUk          # 英语：美/英音标
├─ definitions[]/examples[]
├─ audioUs/audioUk                # 英语：美音/英音（dictvoice type=2 / type=1）
├─ audioUrl                       # 统一发音入口（朗读按钮用；日语 = speech 拼接）
└─ lang                           # 结果所属语言（弹窗标题排版用）
```

## 1.3 读音缓存（ReadingStore，M12）

```
ReadingStore（core/ReadingStore.h，纯逻辑 + JSON 落盘，不依赖 app/Settings）
├─ Entry { word, info{reading, accent, pos, lang}, updatedAt }
├─ 键 = 去空白 + 大小写不敏感（keyOf）
├─ 写入优先级：① 查词成功 putFromDict（权威，覆盖旧值；缺字段保留旧值）
│              ② 分词引擎 Token::reading putFromTokens（MeCab/桥档才有，默认不覆盖）
├─ 拒绝写入：查词失败（ok()==false）、空词、空读音 → 不污染缓存
├─ 查询：find/contains/reading/accent/pos/info（**离线可用，不需要联网**）
├─ 展示：displayWithReading →「漢字（かな）」；displayWithInfo →「漢字 [かな] ② 名词」
├─ 上限 5000 条（超出淘汰最久未更新）
└─ 落盘 <数据目录>/readings.json
```

使用点：字幕悬停提示（显示 `漢字 [かな]`）、生词本条目、闪卡 `reading`、弹幕 `漢字（かな）`。
英语词条此刻不写入读音缓存（`DictEntry.reading` 为空），英语路径显示与 M11 完全一致。


## 2. SubtitleModel（字幕容器）

- 持有 `QVector<Sentence>`，按 start 有序。
- `sentenceIndexAt(ms)`：二分定位。
- `setStudyLang(lang)`：把语言铺到全部句子；语言变化时清空 `tokens` 缓存。
- `mergeBilingual(另一轨)`：重叠占比 > 50% 的译文行合并到 translation。
- `importAsrSegments()`：ASR 段按 gap 合并成句。
- `mergeWithNext / splitAt`：手工断句支持（日语合并/切分不插空格）。
- `saveSrt(includeTranslation)`：导出双语 SRT。

## 3. 持久化文件（数据目录）

```
<数据目录>/
├── adoloop.ini        # QSettings（本应用设置文件）
├── cache/             # 波形峰值缓存 *.wvpk、ASR 结果缓存 *.asr.json
├── recordings/        # 跟读录音 shadow-*.wav、听音查字 soundsearch-*.wav、复述 retell-*.wav
├── dictations/        # 听写记录 *.json（汇报）
├── vocabulary.json    # 生词本（SM-2 字段 + M12 读音字段）
├── sentencebook.json  # 难重点句库
├── flashcards.json    # 原句闪卡（M12 加 reading）
├── playlist.json      # 播放列表（M10）
├── bookmarks.json     # 书签，全量一份、按 media 归属过滤（M10）
├── resume.json        # 断点续播位置，每文件一条（M10）
├── readings.json      # 读音缓存：词 → {reading, accent, pos, lang, updatedAt}（M12）
└── retell.json        # 段落复述练习历史（M12）
```

## 4. 生词本条目（VocabularyEntry，含 SM-2 复习）

```
{ word, addedAt, level(1-5),
  reading, accent, pos, lang,          # M12 日语化：假名/声调/词性/语言（缺则空串）
  contexts:[{sentence, source, at}],
  due, intervalDays, ease(2.5), lapses }
```

- 旧 `vocabulary.json`（无 M12 字段）解析**不失败**，缺字段留空；写回时补全新字段。
- 读音来源优先级：`addWord(..., ReadingInfo)`（查词弹窗）> `ReadingStore`（查词已落盘的缓存）> 空。
- `VocabularyModel::updateSm2(entry, quality 0..5)` 为纯函数，可单测（M12 未改动算法）。

## 5. 闪卡条目（Flashcard）

```
{ cardId, sentenceId/source, prompt(挖空句), answer(被挖词),
  reading,                             # M12：答案词假名（旧卡读盘后可由读音缓存补齐）
  due, interval, ease }
```

## 5.1 段落复述历史（RetellSession::Item，M12）

```
{ media, scope(sentence|chunk|paragraph|full), firstSentence, lastSentence,
  quality(-1..5), score(-1..100), detail, recorded, recordingPath, at, text }
```

- `quality = -1` = 未评；`score = -1` = 未录音（静默回忆模式）。
- 上限 500 条（超出淘汰最早）；脏数据（句区间非法）读盘时丢弃。
- 只有**自评过**的段才写历史（跳过/中途停止不写）。

## 6. 听写记录（DictationReport）

```
{ media, mode(word/sentence/free), startedAt, durationMs,
  items:[{ expected, typed, correct }],
  stats:{ total, correct, accuracy, missedWords } }
```

## 7. 播放列表 / 书签 / 断点续播（M10）

```
PlaylistEntry  { path(规范绝对路径，去重键), title, addedAt, durationMs }
Bookmark       { media(归属键), mediaTitle, timeMs, note, createdAt }
ResumeStore::Entry { positionMs, durationMs, updatedAt }   # 键 = media
```

- 归属键 `media`：本地媒体 = `QDir::cleanPath(QFileInfo(p).absoluteFilePath())`；
  在线媒体 = 标题（直链会过期，不入播放列表）。比较在 Windows 上大小写不敏感。
- 去重：播放列表按路径去重；书签在 ±500ms 内视为同一处（只更新备注）；
  续播记录同键原地更新，不产生重复条目。
- 上限（防脏数据增长）：播放列表 500 条（淘汰最早加入）、单文件书签 200 条（淘汰最早创建）、
  续播 200 条（淘汰最久未更新）。
- 丢弃的脏数据：空路径/空 media、负时间点、重复路径（读盘时跳过）。
- 三个模型均为 `QAbstractListModel`（风格同 FlashcardModel）+ `changed` 信号 → UI 刷新与落盘；
  新文件清单同步登记在 `src/CMakeLists.txt`。

## 8. 数据流约束

- 所有模型与 UI 解耦：列表界面通过 QAbstractListModel 包装（见 TranscriptPanel / FlashcardModel）。
- 时间一律毫秒 int64；播放引擎换算以秒的浮点为准（mpv 事件），边界处统一 `round(x*1000)`。
- 断句参数、快捷键、引擎选择均存 QSettings，支持「恢复默认」。
