# 05 播放内核与波形

## 1. MediaEngine 抽象

```cpp
class MediaEngine : public QObject {
    // open/play/pause/stop/seek/setRate/setVolume
    // position()/duration()/isPlaying()/isLoaded()/lastError()
signals: positionChanged / durationChanged / playStateChanged / eofReached
         loadedChanged / errorOccurred
};
MediaEngine *MediaEngine::create(parent); // mpv 可用→Mpv，否则 Qt
```

统一毫秒制；内部换算秒浮点（mpv 事件）用 `round(x*1000)`。

## 2. MpvMediaEngine（首选）

- **启动**：`mpv --no-config --idle=yes --keep-open=yes --force-window=yes
  --audio-pitch-correction=yes --input-ipc-server=<pipe>`（QProcess 子进程）。
- **IPC**：Windows 命名管道 `\\.\pipe\adoloop-mpv-<pid>`，`QLocalSocket` 收发换行 JSON。
- **观察属性**：`observe_property` time-pos / duration / pause / eof-reached / idle-active；
  属性变化事件 → Qt 信号。
- **命令**：`loadfile` / `set pause` / `seek absolute+exact` / `set speed`（pitch 保持）/
  `set volume` / `stop`。
- **容错**：socket 断线自动重连；mpv 退出时发 errorOccurred；打开在未连接时暂存待加载。
- **降级**：找不到 mpv.exe → `MediaEngine::create` 返回 Qt 后端。

> 未编译期链接 libmpv，规避外部依赖；mpv 缺失时 UI 提示并切回退后端。

## 3. QtMediaEngine（回退）

`QMediaPlayer + QAudioOutput`：播放/定位/音量齐全；`setPlaybackRate` 变速
（部分平台不变调，能力弱于 mpv，文档注明）。错误信号透传。

## 4. Waveform

- 外部 `ffmpeg -i in -f s16le -ac 1 -ar 8000 -` 输出 PCM。
- 按 **10ms 块** 计算 min/max 峰值（8kHz × 10ms = 80 采样/块）。
- 缓存：`<cacheDir>/<sha1(path)>.wvpk`（magic + 时长 + 峰值数组，LittleEndian）；
  命中缓存则跳过解码。
- ffmpeg 缺失：发 `failed`，UI 波形区提示「未找到 ffmpeg」，播放不受影响。
- 绘制聚合在 WaveformWidget（按像素列合并多块）。

## 5. AudioRecorder

- `QAudioSource`（16kHz/单声道/Int16，尽量接近格式）→ WAV 文件。
- start 预写 44 字节头，stop 回填 RIFF 头（按实际文件大小）。
- 供随意读（跟读）、听音查字使用；录音存 `recordings/`。

## 6. AudioAnalysis（启发式，无第三方依赖）

| 能力 | 算法 |
| --- | --- |
| 读 WAV | 解析 RIFF/fmt/data → 归一化浮点 mono |
| RMS 包络 | 25ms 帧、10ms 步进 |
| 声控触发 | VAD：连续 3 帧 RMS>阈值 → 语音起点 ms |
| 跟读比对 | 包络重采样 100 点 → 覆盖度 + Pearson 节奏 + 幅度比 → 0..100 分 |

> 说明：语音评分是启发式包络比对，精度低于专业音素级评测；接口 `compare()` 独立，
> 后续可替换为第三方评测（如按音素对齐的引擎），不影响上层调用。
