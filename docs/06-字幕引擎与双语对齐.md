# 06 字幕引擎与双语对齐

## 1. SubtitleParser（解析）

| 格式 | 处理 |
| --- | --- |
| SRT | 序号 + `HH:MM:SS,mmm --> ...` + 多行文本 |
| VTT | `WEBVTT` 头 + 时间行（点分毫秒） |
| LRC | `[mm:ss.xx]`，无结束时间 → 默认 3s（可经对齐修正） |
| ASS/SSA | `Dialogue:` 行，剥离 `{\...}` 样式标签、`\N` 换行 |

探测：扩展名优先，其次内容嗅探。统一输出 `QVector<Sentence>`。

## 2. SubtitleAligner

### 2.1 智能断句（segmentBySilence）— Aboboo 五参数映射

| 参数 | 实现 |
| --- | --- |
| 背景噪音 | 帧 RMS 阈值（20ms 帧/10ms 步进），`noiseThreshold` 0..1 |
| 句间停顿 | 无声段 >= `minGapMs` → 候选断点 |
| 最短句长 | 短于 `minSentenceMs` 的段并入下一段 |
| 允许杂音数 | 短于 `allowedNoiseMs` 的孤立状态翻转被抹平（毛刺抑制） |
| 静音去除 | 参数保留（v1 波形显示压缩留接口） |

### 2.2 ASR 段 → 句（sentencesFromAsr）

- 停顿 gap <= maxGapMs（默认 600ms）且句长 < 12s → 合并。
- 保留词级时间戳；供抠词听写/弹幕/闪卡复用。

### 2.3 参照对齐（alignToReference）

- 时间重叠最大 + 文本相似度（归一化编辑距离）加权 → 最近邻匹配。
- 相似度 >= 0.6 时用参照文本修正 ASR 文本；附参照译文。

## 3. 双语字幕

- `SubtitleModel::mergeBilingual(另一轨)`：重叠占比 > 50% 的译文行合并进
  `translation`；一行原文可合并多行译文。
- 单行加载双语 SRT（含翻译行）也兼容（导出选项）。

## 4. TranslationProvider（实时翻译）

- 有道网页接口（免 key）：`fanyi.youdao.com/translate?doctype=json&i=<text>`。
- 异步、token 关联、超时；失败回退为空译文并提示。
- 翻译用途：加载单语字幕时批量补译文、听写参考。

## 5. 字幕取词：词级命中（M11）

此前是「点击即查当前句首词」的假实现（`hitTestWord()` 永远返回 `wordList().first()`）。
M11 改为真正按像素命中：

```
SubtitleOverlay::paintEvent
└─ ensureLayout()                        # 惰性重排（resize/换句/换模型时失效）
   ├─ QTextLayout(text, font) + WrapAtWordBoundaryOrAnywhere   # 中日文可在任意字间换行
   ├─ 逐行 createLine → setLineWidth(可用宽) → setPosition(0, y)
   ├─ buildHitMap(text, tokens, font, lineWidth)               # 静态纯函数，可离线单测
   │    每个 token（begin/length）→ 该行内的 x 区间：
   │    x = line.x() + line.cursorToX(pos)    # line.x() 已含居中偏移（自检实测核实）
   │    跨行词 → 每行一个矩形（rects 多于一个）
   └─ m_blockOrigin = 文本块左上角（垂直居中于上半区）

hitIndexAt(pos) → (pos - m_blockOrigin) 落在哪个 token 的矩形内（横向 1px 容差）
```

交互时间轴：

| 事件 | 行为 |
| --- | --- |
| 鼠标移入词 | 该词黄底高亮 + 手型光标，启动悬停定时器（默认 450ms，设置项 `dict/hoverDelayMs`） |
| 定时器到点 | 发 `wordHovered(word, sentenceIndex)`；同一个词不重复触发 |
| AppController | 收到后启动 150ms 去抖定时器，到点 `lookupWord()` 弹词典 |
| 鼠标点击词 | 立即发 `wordClicked(word, sentenceIndex)` |
| 点击空白 / 移出浮层 / 换句 | 清除高亮并发 `hoverCleared()`（控制器停止去抖） |

- 「仅点击时查词」：设置项 `dict/hoverLookup=false`（设置界面「学习」页），
  此时不启动悬停定时器，只保留点击查词。
- 日语按分词结果命中：`私は学生です` 悬停「学生」只查「学生」（自检有专门断言）。
- 译文行维持原绘制方式（整块居中 + 自动换行），不参与命中。

## 6. 日语分词（M11，字幕取词/听写/闪卡的地基）

```
按 Unicode 类别切 run：漢字(含々〆〇ヵヶ) / ひらがな / カタカナ(含ー) / 拉丁 / 数字 / 其他
├─ 片假名、拉丁、数字 run → 各自整体成词
├─ 漢字 run + 后邻平假名 run：
│   ├─ 平假名以助词/助动词白名单开头 → 汉字不合并，白名单前缀独立成词
│   │    私は学生です → 私 / は / 学生 / です
│   │    今日はいい天気ですね → 今日 / は / いい / 天気 / です / ね
│   ├─ ≤3 字 → 整体并入（食べる / 大きい / 行きます）
│   └─ >3 字 → 只并入 1 个送假名（食べなかった → 食べ / なかった）
├─ 独立平假名 run → 整体成词（おいしい / すしをたべる）
└─ 标点/空白/记号丢弃（含全角与日文约物）
```

- 白名单：`は,が,を,に,で,と,も,へ,や,の,か,ね,よ,な,です,ます,ました,ません,だ,た,て,から,
  まで,より,など,ので,のに,けど,し,ば,ながら,たり,って`（`Tokenizer::isParticleOrAuxiliary`）。
- `ー` 紧跟前一平假名 run 时并入该 run（`らーめん`），否则属片假名。
- 每个 token 带 `begin/length`，供字幕像素级命中；外部两档（MeCab / Python 桥）额外提供
  读音与原形，详见 `docs/09` 与 `docs/11`。

## 7. 局限与后续

- LRC 结束时间缺失：需在断句后重排；v1 用默认 3s。
- 「字幕时间规整」完整版（ASR 词级时间戳整体校正字幕偏移）留待后续增强；
  现有 alignToReference 提供基础最近邻匹配。
- 内置日语分词是启发式（无词性/活用分析），整段平假名不切分（如 `すしをたべる` 作一词）；
  需要更准切分时安装 MeCab，或在设置里填 python + `pip install janome`（自动走桥脚本）。
