# 08 学习模式设计

## 1. 复读 RepeatSession（有穷状态机）

```
Idle → Playing → Waiting(间隔) → Repeating → Playing → … → Finished
```

| 模式 | 行为 |
| --- | --- |
| 逐句 | 播放 [start,end]；到句末暂停→间隔→重复 N 次→下一句（autoAdvance 可关） |
| A-B | 播放 [A,B]；到 B 重头，直到手动停止 |
| 全文方案 | 从指定句起逐句带重复通读全篇 |

驱动方式：AppController 把 `positionChanged` 回灌 `tick(pos)`，`eofReached` 回灌 `onEof()`；
会话通过命令信号（playRange/seek/pause）反向驱动引擎。间隔用 QTimer。

## 2. 随意读 ShadowingSession（跟读）

```
Idle → PlayingModel → (方式分支) → Recording → Comparing → Finished
```

| 方式 | 链路 |
| --- | --- |
| 手动 | 播原音→停止→用户点录音→录音→比对 |
| 声控 | 播原音→缓冲录音→VAD 轮询（100ms）→检测到人声→正式录音→尾静音 1.5s 结束 |
| 疯狂 | 播原音→立即下一句（弱化比对，练流畅度） |

- **缓冲录音**：`AudioRecorder::startToBuffer()`（内存 QIODevice）供 VAD 与裁剪。
- **比对**：`AudioAnalysis::compare`（包络重采样 100 点 → 覆盖度 30% + 节奏相关 50% + 幅度 20%），
  0..100 分；模型音 PCM 由 AppController 用 ffmpeg 按句提取（异步）。
- 录音默认存 `recordings/`（可导出）。

## 3. 听写 DictationSession

| 模式 | 流程 | 纠错 |
| --- | --- | --- |
| 抠词 | 播一句→输词自动归位（无序）→未填词自动复读词区间→完成进下句 | 输错标红；未填词入错词表；整句完成出汇报 |
| 单句 | 播一句→整句输入→回车判定→下一句 | 归一化比较（忽略标点/大小写可配） |
| 自由 | 连续播放→逐句输入→分段汇报 | 同上 |

- 汇报 `Report`：items / total / correct / accuracy / missedWords → JSON 存 `dictations/`。
- 词区间来自 `Sentence::estimatedWords()`（ASR 词级时间戳优先）。

## 4. 造句 SentenceBuilder

- 原句 → `splitToWordChips`（词+尾随标点）→ Fisher-Yates 洗牌 → 用户点选重组。
- `check()`：先精确比较，再归一化容错。

## 5. 原句闪卡 FlashcardModel（Echo-Loop）

- 从当前句生成挖空卡（取长词，`____` 替换）。
- SM-2：quality 0..5 → interval 1→6→×ease；ease 增减；lapses 计数。
- 双态：既是模型又是 QAbstractListModel（待复习队列直接列表展示）。
- 持久化 `flashcards.json`。
- **M12 日语化**：卡片补 `reading`（答案词假名），新卡生成时从 `core/ReadingStore` 取，
  读盘后 `fillMissingReadings()` 给缺读音的旧卡补齐；列表/揭晓处显示 `答案（かな）`
  （`FlashcardModel::answerWithReading`，无读音时退回原词）。旧 `flashcards.json` 无该字段照常解析。

## 6. 生词本 VocabularyModel（分级 + SM-2）

- 添加带上下文（{句子, 来源}，最多 20 条）；重复添加 → 提级。
- `applySm2` 与闪卡同一套间隔算法（纯函数可单测）。
- 持久化 `vocabulary.json`。
- **M12 日语化**：条目补 `reading` / `accent` / `pos` / `lang`；来源优先级
  ① `addWord(..., ReadingInfo)`（查词弹窗路径）② `ReadingStore`（查词成功时已落盘的缓存）
  ③ 留空。已有条目只补空缺、不覆盖。左侧列表显示为
  `漢字 [かな] ② 名词 — 上下文`（`ReadingStore::displayWithInfo`），无读音时退回原样式 `词 [等级]`，
  悬浮提示给出读音/词性/等级/到期/上下文条数。旧 `vocabulary.json`（无这些字段）照常解析。

## 7. 弹幕复习 DanmakuController（幕境）

- 句切换时扫描本句生词（`estimatedWords` ∩ 生词本）→ 发射弹幕事件。
- 每句最多 4 条；同一词首现标记 isNew（复习 vs 新学视觉区分）。
- 弹幕渲染在 DanmakuWidget（右→左、多轨道、点击可查词）。
- **M12 日语化**：`Item::reading` 随生词本条目/查词结果带上，飘出文本为
  `漢字（かな）`（`Item::display()`），点击仍按原词查词。

## 8. 状态机共约

- 全部会话类为纯逻辑（不依赖 UI），命令经信号由 AppController 执行，
  位置/录音数据由外部回灌——便于单测与替换后端。

## 9. 段落复述 RetellSession（M12，Echo-Loop 链路 / P0 第 10 条）

```
Idle → PlayingModel → Concealed(隐藏原文) → Retelling(可选录音) → Revealed(揭晓对照)
     → SelfRating → (下一段 PlayingModel) → … → Finished
                      ↑                              │
                  stop() 任意状态 ──────────────→ Idle
```

| 状态 | 含义 | 出口 |
| --- | --- | --- |
| PlayingModel | 播放本段原音（**字幕浮层此刻已隐藏原文**，避免边听边看） | `tick(pos>=段末)` 或 `onModelFinished()` |
| Concealed | 静默回忆：只显示字数占位 | `reveal()`（直接揭晓）/ `onUserStartRetelling()`（有麦克风则录音） |
| Retelling | 复述录音中（缓冲录音，内存） | `onUserStopRetelling()` → `commandStopBufferRecording` → 数据回灌 |
| Revealed | 揭晓原文/译文 + 包络比对得分 | `rate(0..5)` / `nextSegment()` |
| SelfRating | 过渡态：写历史（范围/句区间/评分/时间/媒体）后立即前进 | → 下一段 PlayingModel 或 Finished |

- **范围 Scope**：`Sentence`（当前句起每句一段）/ `Chunk`（意群）/ `Paragraph`（连续 N 句，N 可配，
  默认 3）/ `FullScript`（全文一段）。`buildSegments()` 为纯函数（可离线单测），越界 fromIndex 自动夹紧。
  - 意群**优先复用 `Sentence::chunks()`**（词级时间戳/停顿时长）；M11 起内置分词会剥掉标点，
    `chunks()` 常退化成「整句 1 段」——此时按文本标点（`、。！？，…` 等）做按时长比例的二次切分，
    保证「意群」确实比「当前句」细；两段时长合计 = 原句时长，首尾与句首尾对齐。
- **无麦克风 / 不录音降级**（必须可用）：`Config::micAvailable`（app 层用
  `AudioRecorder::inputAvailable()` 探测）为 false 或用户关闭录音时，`canRecord()` 为 false，
  Concealed 下 `onUserStartRetelling()` 直接 `reveal()`，不启动录音、不报错、不卡死，
  并给出中文 `notice`（「未检测到麦克风：已降级为…」）。链路变为
  **静默回忆 → 揭晓对照 → 自评**。
- **录音与评分**：复用 `AudioRecorder::startToBuffer()`（缓冲模式）与
  `AudioAnalysis::compare`（包络比对：覆盖度 30% + 节奏 50% + 幅度 20%，与跟读同一口径，
  0..100 分；未录到声音时 `detail` 记「未检测到有效复述语音」、历史里 `score = -1`）。
  原音 PCM 由 AppController 用 ffmpeg 按段区间提取（异步回灌 `onRecordingData`）。
  录音存 `recordings/retell-*.wav`（16kHz 单声道 WAV，与跟读同格式）。
- **历史**：`retell.json`（上限 500 条，超出淘汰最早），字段
  `{media, scope, firstSentence, lastSentence, quality, score, detail, recorded, recordingPath, at, text}`；
  跳过（`nextSegment()`）不计入历史，只有自评过的段才写。
- **UI 职责划分**：`ui/RetellWidget` 只做展示与收集操作（范围下拉/段落句数/录音开关/开始·停止/
  开始复述·说完了/揭晓对照/下一段/自评 0–5/历史列表），全部判断落在会话里；
  `SubtitleOverlay::setConcealed(bool)` 负责「隐藏文本落到底」——隐藏期间不绘制原文/译文、
  词级命中表为空（悬停/点击都取不到词，杜绝用查词弹窗偷看），音频照常播放。
