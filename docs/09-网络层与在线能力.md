# 09 网络层：yt-dlp / 词典 / 翻译

## 1. HttpClient

- `QNetworkAccessManager` 封装：GET + 超时（默认 15s）+ 回调 `(body, status, err)`。
- 上下文对象用 `QPointer` 守卫：请求方销毁后丢弃回调，避免悬垂。

## 2. YtDlpRunner（在线播放 / 字幕下载）

| 能力 | 命令 | 解析 |
| --- | --- | --- |
| 解析直链 | `yt-dlp -J --no-playlist <url>` | title / duration / url 或 requested_formats[0].url |
| 直链兜底 | `-g -f bestaudio[ext=m4a]/bestaudio/best` | stdout 输出 URL |
| 字幕下载 | `--skip-download --write-subs --write-auto-subs --sub-langs <lang> --convert-subs srt` | 取最新生成的 srt/vtt |

- 全异步（QProcess 信号）；每次运行用一次性 QProcess 避免重复连接。
- 缺失 yt-dlp → 明确提示，其余功能不受影响。

## 3. DictionaryProvider（即点即查 / 发音 / 听音查字入口）

- 有道 jsonapi（免 key，非官方接口，标注仅供个人学习）：
  `dict.youdao.com/jsonapi?q=<词>&le=<jap|en>`，**按学习语言选节点**。
- 解析实现在 `net/DictionaryParser.{h,cpp}`（纯函数、可离线单测，`src/net` 层，不依赖 Settings）；
  Provider 只负责拼 URL 与派发：

| 语言 | 请求 | 表记 | 读音/音标 | 声调 | 释义 | 例句 | 发音 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 日语 | `le=jap` | `jc.word[].origin` | `jc.word[].return-phrase.l.i`（假名） | `phonesup`（`0`→`⓪`） | `trs[].pos` + `trs[].tr[].l.i` | 方括号条目（`[…] 中文`） | `speech` 字段 |
| 英语 | `le=en` | `query` → `ec.word[].return-phrase.l.i` → `simple.word[].return-phrase` | `ec.word[].usphone/ukphone/phone` | — | `ec.word[].trs` 与 `ec.trs`（两种形态都收） | `blng_sents_part.sentence-pair` | `usspeech`/`ukspeech` |

- **实测结构修正（M11）**：`le=en` 响应里 `ec.word` 是**数组**且 `trs` 在数组元素内部、
  顶层可能没有 `query` —— 旧的「按对象解析」写法会拿不到音标与释义；现已兼容数组/对象两种形态。
- 发音音频 URL（`dictvoice`，实测返回 `audio/mpeg`）：
  - 日语：`https://dict.youdao.com/dictvoice?audio=<speech>`（`speech` 已是百分号编码的假名 + `&le=jap`）；
    含 `・` 的多读音 speech（如 `た·べる`）实测返回 500 → 自动回落
    `audio=<表记>&le=jap`（实测 200）。
  - 英语：`audio=<word>&type=2`（美音）/`&type=1`（英音），优先用词典给的 `usspeech`/`ukspeech`。
- 播放由 `core/PronunciationPlayer`（独立 `QMediaPlayer` + `QAudioOutput`）负责，
  **不经过 mpv 主播放**，因此朗读不会打断复读/跟读；失败经 `failed()` 给中文提示。
- 失败 → `failed(token, err)`（中文提示）；弹窗显示「重试」。
- **读音落盘（M12）**：查词**成功**时 `AppController` 把 `{word, reading, accent, pos, lang}`
  交给 `core/ReadingStore` → `readings.json`；失败不写。之后生词本/闪卡/弹幕/字幕悬停
  都从缓存取读音，**无需联网**（优先级：词典 > 分词引擎读音；详见 `docs/04` 第 1.3 节）。
- 接口设计预留本地字典（MDX）接入：只需实现同一 `lookup(word, token)`。

## 3.1 日语分词增强（可选，联网无关）

| 档位 | 触发 | 说明 |
| --- | --- | --- |
| MeCab | 设置里填 MeCab 路径/命令名且可执行 | 子进程按行分词（stdin/stdout），取 词/读音/原形（读音转平假名） |
| Python 桥 | 设置里填 python 路径 | `scripts/japanese_tokenizer_bridge.py`（janome / fugashi），逐行 JSON 协议，风格同 faster_whisper 桥 |
| 内置启发式 | 默认 | 无外部依赖，详见 `docs/06` 第 6 节 |

两档外部引擎都**缺失/失败自动降级**（不报错、不阻塞），且只处理有限行数
（`Tokenizer::Options::maxBatchLines`，默认 500）后一次性返回。

## 4. TranslationProvider（实时翻译 / 批量译文）

- 有道网页翻译（免 key）：`fanyi.youdao.com/translate?doctype=json&i=<text>`。
- token 关联；AppController 批量给无译文句子补译（m_pendingTrans: token→句索引）。
- 源语言默认跟随学习语言（日语 `ja`），目标语言默认 `zh`（可在设置里改）。
- 失败静默（译文留空），不阻塞学习流程。

## 5. 安全与边界

- 所有请求仅 GET 公开接口，无鉴权信息写入日志。
- 网络失败均有超时与错误回传；UI 只读提示，不弹阻塞对话框（听写/播放不中断）。
