# 10 快捷键与界面布局

## 1. 快捷键架构（LPlayer 风格，全自定义）

- `Settings::defaultKeyBindings()` 为默认键位表（actionId → QKeySequence）。
- `Settings::keySequence(id)`：设置覆盖优先，否则回退默认。
- `AppController::registerActions()`：QAction + `setShortcut` 统一注册，
  菜单项与快捷键同源（改设置即改菜单）。
- `SettingsDialog` 快捷键页：QKeySequenceEdit 逐项编辑、冲突检测（重复键位标红）、
  恢复默认。

| 动作 | 默认键 | 说明 |
| --- | --- | --- |
| play.pause | Space | 播放/暂停 |
| play.stop | S | 停止 |
| play.forward5 / back5 | L / J | ±5 秒 |
| play.speedUp / Down | Alt+↑ / ↓ | 变速 |
| play.volumeUp / Down | Ctrl+↑ / ↓ | 音量 |
| study.prev/nextSentence | P / N | 上/下一句 |
| study.repeatSentence | R | 复读本句 |
| study.abLoop | B | A-B 循环 |
| study.shadowing | F | 随意读（录音中再按=停止） |
| study.dictation | D | 听写 |
| study.sentenceBuild | Ctrl+G | 造句 |
| study.flashcard | Ctrl+F | 原句闪卡 |
| study.retell | Ctrl+R | 段落复述（M12；练习中再按 = 停止） |
| study.lookupWord | Q | 查当前词（M11：优先查悬停中的词） |

## 2. 主窗口布局

```
┌──────────┬───────────────────────────────┬──────────────┐
│ 左 Tab    │ 媒体区（mpv 窗口/占位）         │ 右 Tab        │
│ 播放列表   │  ┌─ SubtitleOverlay（双语）    │ 字幕侧栏      │
│ 书签      │  └─ DanmakuWidget（弹幕）      │ 听写          │
│ 生词本    │ ───────────────────────────── │ 造句          │
│ 闪卡      │  WaveformWidget（句段+AB）      │ 复述（M12）    │
│          │  RepeatControls                │              │
│          │  PlayerControls（进度/变速/音量）│              │
└──────────┴───────────────────────────────┴──────────────┘
                         状态栏（后端/提示/跟读得分/复述状态）
```

- 复述进行中 `SubtitleOverlay` 进入隐藏态：不绘制原文/译文，只显示「◇ 原文已隐藏 · 复述练习中」
  与字数提示，并按 `setConcealed(true)` 清空命中表（悬停/点击取不到词）；音频照常播放。

| 组件 | 信号 | 处理 |

## 3.1 字幕浮层交互参数（M11，设置界面可调）

| 项 | 设置键 | 默认 | 说明 |
| --- | --- | --- | --- |
| 悬停即查词 | `dict/hoverLookup` | 开 | 关闭 = 仅点击时查词 |
| 悬停触发延时 | `dict/hoverDelayMs` | 450 ms | 浮层内的悬停定时器；到点才发 `wordHovered` |
| 查词去抖 | （内置 150 ms） | — | AppController 侧再次延时，避免快速划过时连环请求 |
| 学习语言 | `lang/study` | `ja` | 决定分词、词典节点、ASR 语言跟随 |

## 3.2 新增窗口/入口（M11）

- `工具 → 听音查字…`（Ctrl+Y）：`SoundSearchDialog`，模型无关的独立对话框，
  录音按钮文案在「录音 / 停止并识别」间切换；ASR 未安装时在对话框内给出中文提示。
- 词典弹窗（`DictionaryPopup`）日语标题为 `表记 [假名] 声调`；「朗读」按钮在词典未给音频时置灰。

## 3.3 段落复述面板与设置（M12）

- `学习 → 段落复述`（Ctrl+R）：右 Tab 第 4 页「复述」，`ui/RetellWidget`。
  控件：范围下拉（当前句 / 意群 / 段落（连续 N 句）/ 全文）、段落长度 spin（1–20 句）、
  「复述时录音」勾选、开始复述 / 停止、开始复述（录音）/ 说完了、揭晓对照 / 下一段、
  自评下拉（0 完全说不出 … 5 完整流利）+ 记录自评、提示行、练习历史列表（最近 30 条）。
- 设置项：`study/retellParagraphSize`（默认 3）、`study/retellRecord`（默认开）；
  均在「设置 → 学习」页可改，改动即写入设置并重新注入会话（`applyRetellSettings()`）。
- 无麦克风时：`AudioRecorder::inputAvailable()` 为 false → 面板提示「未检测到麦克风」，
  「开始复述（录音）」置灰，链路自动变为「静默回忆 → 揭晓对照 → 自评」。
- 生词本/闪卡列表（M12）：日语生词显示 `漢字 [かな] ② 名词 — 上下文`，闪卡显示 `挖空句 → 答案（かな）`；
  悬浮提示给出读音/词性/等级/到期与卡片来源。字幕悬停提示在读音缓存命中时显示 `漢字 [かな]`。

## 4. 降级与提示

- mpv 缺失 → 状态栏提示 + Qt 后端。
- ffmpeg 缺失 → 波形区提示。
- 无字幕 → 状态栏提示 Ctrl+E 生成。
- MeCab / janome（Python 桥）缺失 → 自动用内置日语分词（状态栏/设置界面说明，不报错）。
- 听音查字未装 ASR → 对话框内提示「可直接输入查询」，输入框路径照常可用。
- 段落复述无麦克风（或用户关闭录音）→ 自动降级「静默回忆 → 揭晓对照 → 自评」，
  面板与状态栏给出中文提示，不启动录音、不报错。
- 复述录音设备启动失败 → 状态栏提示并按静默回忆收尾（会话不会卡在录音态）。
- 词典发音失败（网络/音频地址无效）→ 状态栏中文提示（不打断播放）。
- 全部为状态栏/对话框内提示，不打断当前学习流程。
